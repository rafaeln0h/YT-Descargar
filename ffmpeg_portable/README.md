# FFmpeg portable

Esta carpeta no distribuye binarios. Coloca `ffmpeg.exe` y `ffprobe.exe` bajo
`ffmpeg_portable/bin/`, obtenidos de una fuente confiable, o instala FFmpeg en
`PATH`.

Los ejecutables están ignorados por Git para evitar archivos grandes,
actualizaciones inseguras y licencias/atribuciones incompletas.

Consulta las opciones oficiales en <https://ffmpeg.org/download.html>.
