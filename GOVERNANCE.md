# Gobierno del proyecto

YT-Descargar es un proyecto mantenido por `@rafaeln0h`.

## Decisiones

- El mantenedor define alcance, roadmap, versiones y publicaciones.
- Issues y pull requests son propuestas; requieren revisión y autorización
  explícita antes de integrarse.
- Cambios de seguridad, licencias, telemetría, proveedores externos, red o
  almacenamiento necesitan aprobación del mantenedor.
- `CODEOWNERS` solicita su revisión en todo el repositorio.

## Principios

1. Acceso gratuito y código fuente disponible.
2. Uso responsable de contenido y respeto de derechos.
3. Funcionamiento local y privacidad por defecto.
4. Metadatos verificables con procedencia.
5. Compatibilidad progresiva sin prometer plataformas antes de validarlas.

Si el equipo crece, este documento podrá definir roles de triage, revisión y
publicación. Hasta entonces, una aprobación de terceros no sustituye la del
mantenedor.
