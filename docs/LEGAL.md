# Uso responsable

Esta herramienta es un cliente local y no otorga derechos sobre contenido.
Antes de descargar, confirma que el material es:

- creado por ti;
- de dominio público;
- distribuido con una licencia que permita la copia;
- autorizado expresamente por el titular; o
- permitido por la legislación aplicable a tu situación.

YouTube ofrece funciones oficiales de descarga en algunos productos y regiones.
El uso de herramientas de terceros puede entrar en conflicto con términos del
servicio. Consulta los
[Términos de YouTube](https://www.youtube.com/static?template=terms). No se
incluyen mecanismos para eludir DRM, controles de pago o acceso no autorizado.

Las tiendas móviles aplican reglas adicionales. Apple exige autorización para
guardar, convertir o descargar medios de terceros; consulta
[Apple App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)
y el [plan móvil](MOBILE_AND_CROSS_PLATFORM.md).

La aplicación debe permanecer ligada a `127.0.0.1` salvo que se añadan
autenticación, CSRF, límites, aislamiento de archivos y una revisión de
seguridad para modo servidor.
