# YT-Descargar v0.013

Fecha: 2026-08-10.

Actualización centrada en descargas confiables, discografías de YouTube Music,
organización de sencillos y soporte completo del motor yt-dlp actual.

## Destacados

- Sencillos oficiales agrupables en `Artista/Singles`, por año, por lanzamiento
  o mediante una plantilla personalizada.
- Detección de discografías que separa álbumes, EP, sencillos, playlists y videos.
- Recuperación de descargas interrumpidas y reconciliación de pendientes sin
  workers activos, conservando progreso y archivos ya creados.
- yt-dlp 2026.07.04 con `yt-dlp-ejs`, Deno y `curl-cffi`; Node.js se mantiene
  como runtime de respaldo.
- Selección automática del cliente de YouTube para evitar forzar `web_music`
  sin GVS PO Token.
- Diagnóstico visible de Python, yt-dlp, EJS, Deno/Node, FFmpeg/ffprobe y
  proveedores opcionales de PO Token.
- Python mínimo 3.11 y matriz CI en Windows/Ubuntu con Python 3.11 y 3.13.

## Actualización desde v0.012

1. Descarga `YT-Descargar-v0.013.zip` desde la sección Assets de la release.
2. Compara su SHA-256 con `SHA256SUMS.txt`.
3. Extrae el ZIP en una carpeta nueva o conserva primero una copia de tu carpeta
   actual.
4. Ejecuta `start.bat`; el launcher actualizará el entorno virtual con las
   dependencias compatibles.

La configuración e historial del usuario permanecen en su carpeta personal. El
valor heredado `default,web_music` se interpreta como `auto`, por lo que no es
necesario editar manualmente `.ymd_config.json`.

## Compatibilidad

- Python 3.11 o posterior.
- Windows como plataforma principal; pruebas automatizadas en Windows y Ubuntu.
- FFmpeg/ffprobe en `PATH` o en `ffmpeg_portable/`.
- Deno instalado con las dependencias de Python; Node.js 22+ puede usarse como
  respaldo.

## Validación

- 74 pruebas unitarias correctas.
- Ruff, `compileall` y `pip check` correctos.
- Extracción real simulada de YouTube Music con Deno 2.9.5 y EJS 0.8.0.

## Limitaciones conocidas

- No se distribuye FFmpeg dentro del ZIP de la release; `start.bat` puede
  configurarlo en Windows o puede instalarse por separado.
- Los proveedores de PO Token son plugins de terceros y no se instalan
  automáticamente.
- No hay instalador firmado; el artefacto publicado es un ZIP del código listo
  para iniciar con `start.bat`.
