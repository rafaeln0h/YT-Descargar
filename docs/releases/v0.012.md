# YT-Descargar v0.012

Fecha: 2026-07-31.

Primera entrega pública preparada para contribuciones. Convierte el prototipo en
una base documentada, observable y extensible.

## Destacados

- Tags musicales, técnicos y de procedencia multiformato.
- Enriquecimiento conservador con YouTube Music, MusicBrainz, AcoustID y Discogs.
- Metadatos y letras incrustados sin JSON adicional por descarga.
- Biblioteca por artistas, álbumes, playlists, canciones y videos, con reproductor completo.
- Covers cuadrados, reparación en lote, overrides manuales y análisis ReplayGain.
- Interfaz unificada con pestañas, transiciones, PWA y notificaciones opcionales.
- Logs rotativos y API de diagnóstico/capacidades.
- Gobierno, licencia, seguridad, templates y CI.
- Investigación de alternativas abiertas/comerciales y roadmap móvil.

## Compatibilidad

- Python 3.10+.
- FFmpeg/ffprobe disponibles en PATH o `ffmpeg_portable/`.
- Windows como plataforma validada principal.
- Linux y macOS previstos por arquitectura, pendientes de matriz CI completa.

## Actualización

La configuración existente en `~/.ymd_config.json` se fusiona con los nuevos
valores. Los metadatos ampliados y las letras disponibles se incrustan por
defecto y pueden deshabilitarse en Configuración.

## Limitaciones conocidas

- La cola se persiste localmente; una descarga que ya ejecuta FFmpeg depende de que
  el proceso de la aplicación continúe activo.
- El enriquecimiento depende de red y puede no encontrar coincidencias seguras.
- MKV/WebM no reciben tags internos del módulo actual en v0.012.
- No hay instalador firmado ni aplicación móvil.
- La funcionalidad depende de cambios externos de YouTube y yt-dlp.
