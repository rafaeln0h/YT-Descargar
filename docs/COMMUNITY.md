# Comunidad y solicitudes

El intercambio público ocurre en GitHub. Antes de publicar, elimina cookies,
tokens, URLs firmadas, rutas personales, fragmentos de audio y cualquier dato
que no deba quedar visible.

## Dónde escribir

| Necesidad | Canal |
|---|---|
| Error reproducible | [Nuevo reporte de error](https://github.com/rafaeln0h/YT-Descargar/issues/new?template=bug_report.yml) |
| Tag, cover, carpeta o numeración incorrecta | [Problema de metadatos](https://github.com/rafaeln0h/YT-Descargar/issues/new?template=metadata_problem.yml) |
| Propuesta concreta | [Solicitud de mejora](https://github.com/rafaeln0h/YT-Descargar/issues/new?template=feature_request.yml) |
| Pregunta de instalación o uso | [Pregunta](https://github.com/rafaeln0h/YT-Descargar/issues/new?template=question.yml) |
| Idea abierta, encuesta o experiencia | [GitHub Discussions](https://github.com/rafaeln0h/YT-Descargar/discussions) |
| Vulnerabilidad | [Aviso privado de seguridad](https://github.com/rafaeln0h/YT-Descargar/security/advisories/new) |

## Información útil

Incluye la versión de YT-Descargar, sistema operativo, pasos mínimos, resultado
esperado y observado. Para metadatos, añade una URL pública de ejemplo y la
fuente que confirma el valor correcto. El mantenedor puede pedir el diagnóstico
saneado disponible en **Configuración > Sistema**, pero nunca credenciales.

Las solicitudes se revisan por impacto, seguridad, mantenimiento, compatibilidad
y uso legítimo. Publicar una propuesta no garantiza que se implemente.
