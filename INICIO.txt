================================================================================
  YT-DESCARGAR 0.013
================================================================================

INICIO RAPIDO:

  1. Descarga la ultima version desde:
     https://github.com/rafaeln0h/YT-Descargar/releases/latest

  2. Verifica el SHA-256 indicado en SHA256SUMS.txt

  3. Extrae el ZIP y haz doble clic en: start.bat

  4. Se abrira automaticamente en: http://127.0.0.1:5000

  5. Pega URL de YouTube o YouTube Music

  6. Haz clic en "Detectar"

  7. Haz clic en "Descargar"

ESO ES TODO!

OPCIONES DE INICIO:
  - start.bat               -> inicia en puerto 5000 (o siguiente libre)
  - start.bat 5001          -> intenta iniciar en 5001 (o siguiente libre)
  - start.bat 5000 debug    -> inicia con debug de Flask

================================================================================

REQUISITOS:
  - Python 3.11+ (https://www.python.org/downloads/)
  - FFmpeg/ffprobe en PATH o conexion para configurarlo en Windows

FEATURES:
  - Playlists completas
  - Albums
  - Videos individuales
  - Canales completos
  - Perfil MP3 320 kbps por defecto (limitado por la calidad de origen)
  - Metadatos automaticos, tecnicos y de procedencia
  - Metadatos y letras incrustados sin archivos .info.json adicionales
  - Album art automatico
  - Organizacion inteligente (artista/album/ano)
  - Sencillos agrupados por artista
  - Diagnostico de yt-dlp, EJS, Deno/Node y FFmpeg

SI NO FUNCIONA:

  Error: "ModuleNotFoundError"
  Solucion: python -m pip install -U -r requirements.txt

  Error: "Port 5000 already in use"
  Solucion: start.bat 5001

  Error: FFmpeg no encontrado
  Solucion: python setup_ffmpeg.py (Windows) o instala FFmpeg en PATH

IMPORTANTE:
  Descarga solo contenido propio, de dominio publico o autorizado.
  Consulta docs\LEGAL.md.
